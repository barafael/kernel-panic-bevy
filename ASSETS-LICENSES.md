## Game content

Everything under `kernel-panic/assets/` comes from the original
Kernel Panic, except as noted below. `original-game-license-info.txt`
is the original game's licence notice, kept unchanged.

| Content | Source | Licence |
|---|---|---|
| Unit, weapon and explosion definitions (`defs/`), models and textures (`units.kpu`), unit pictures, cursors, bitmaps, `sfx/`, sounds and the tips voice-over | Kernel Panic 4.9 by Boirunner, KDR_11k, zwzsg and others | Public domain |
| `readme.txt` (below its first section) | Kernel Panic 4.9 | Public domain |
| Maps Marble Madness, Direct Memory Access 0.5c and 0.5e | Kernel Panic 4.9 | Public domain |
| Maps Central Hub, Corrupted Core, Dual Core, Quad Core | FireStorm and others, Kernel Panic 4.9 | CC BY-SA |
| Maps `deadlock_v1`, `token_ring_v1`, `heap_fragmentation_v1`, `three_way_handshake_v1`, `pipeline_v1`, `circular_buffer_{3,4,5,6}_v1` | This project, generated by `spring-map/examples/` in the Core maps' style | CC BY-SA 4.0, <https://creativecommons.org/licenses/by-sa/4.0/> |
| `readme.txt`'s first section, the in-game credits text | This project | GPL-3.0-or-later, like the code |

The new maps' layouts follow Beyond All Reason maps: Hooked by Raghna
(`deadlock_v1`), Asteroid Mines (`token_ring_v1`), Sinkhole Network
(`heap_fragmentation_v1`), The Desert Triad and Pillar of Doom
(`three_way_handshake_v1`) and SpeedMetal (`pipeline_v1`). Only the
ideas are borrowed; no data from those maps is included.

## Excluded: status unknown

The following files ship with the game as they came in the Kernel Panic
4.9 release, but **this project grants no licence for them**: their
licence was never stated, and the rights stay with their authors.

- Maps whose status the original notice calls unknown: Major Madness 3.0,
  Speed Balls 16 Way.
- Maps the original notice does not mention: Data Cache L1,
  DigitalDivide PT2, Hex Farm 8, Memory Bank v3, Palladium 0.5 (beta),
  pacman, Spooler Buffer 0.5 beta.
- The music (`kernel-panic/assets/music/`): tracks by ParagonX9, Lo-Bat.,
  Mister Beep, Radix, and arrangements by Dreamfish, Stalker,
  Warwick Gaetjens, Front 6 and Wire of music by Rob Hubbard, Emax,
  Matt Gray and Jochen Hippel. The original credits file
  (`kernel-panic/assets/music/credits.txt`) carries no licence statement.

If you are the author of any of these and want them licensed or removed,
please open an issue.
